# Course and Student Mapping Project

A simple Python project demonstrating an object-oriented **One-to-Many relationship** (`1` Course to `many` Students) using a Python list and custom methods.

## Files Included
* `realLifeRelationship.py`: Contains the `Student` and `Course` classes, along with the `add_student` method implementation.
* `diagram.png`
